# PulseRing X1 产品资料包（基于中国真实智能硬件公开资料改编）

本文件夹存放 Zhihu Bridge 演示案例 **PulseRing X1 智能健康与运动指环** 的完整原始产品资料，供评委查阅或直接上传体验完整流程。

## 现实产品参考来源与改编边界

本资料包以中国智能硬件出海标杆产品的公开硬件规格与众筹实践为基础进行合理改编：

### 现实产品公开规格来源
1. **[RingConn Gen 2（玖治科技，深圳/珠海）](https://ringconn.com/products/ringconn-gen-2)**
   - 海外众筹标杆：Kickstarter 上线 8 小时破百万美元、最终超 440 万美元。
   - 公开参考规格：航天级钛合金外壳 + PVD 镀层 + 医用级环氧树脂内衬；超薄 2.0 mm / 宽 6.8 mm / 约 2–3 g 无感佩戴；PPG 光学心率与血氧、皮肤温度、三轴加速度计；BLE 5.0 与 5–7 天本地离线存储；便携式 USB-C 无线充电仓；Sizing Kit（6–14 号）先试戴再发货流程；零订阅费（No Subscription Fee）模式；非医疗器械合规边界声明。
2. **[星纪魅族 StarV Ring 2](https://www.meizu.com/starv/summary_ring2)**
   - 公开参考规格：5 ATM / IP68 生活防水（支持洗手与泳池浅水活动）、双路光学传感器采样架构、便携无线充电收纳仓与多端生态联动设计思路。
