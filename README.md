# Zhihu Bridge · 知乎跨文化认知转译舱

面向内容出海的编辑工作台。根据目标语言与受众，使用知乎资料解释文化语境，提供不同转译策略，并检查译稿是否保留关键事实或引入未经证实的声称。

## 本地启动

安装 Python 3.10 或更新版本，在 `app/` 下执行 `python start.py`。启动后访问 [本地工作台](http://127.0.0.1:8787/)。

Windows 也可以运行 `start.bat`。仓库包含当前前端构建。修改前端后可用 Node.js 24 和 `python start.py --rebuild-web` 重新构建。

实时模型和知乎检索通过环境变量配置。配置项见 [环境变量示例](app/.env.example)，运行方式、离线演示和验收命令见 [中文使用说明](app/README_zh.md)。

## 项目结构

- `app/server/` 提供 API、模型适配器、转译和检查流程。
- `app/web/` 包含前端源码与可运行构建。
- `app/fixtures/` 包含演示案例、证据条目和离线验收数据。
- `prototype/` 提供可用浏览器直接打开的独立界面原型。
